Introduction

MU is a brain-to-video project that integrates the organic and the digital mind.

From an EEG device we extract brain data, such as brainwave frequency, and use this as data to interpolate within a machine learning model's latent space. Therefore, as the user's brain state evolves, so too does the output of the model, and as the participant observes the model's output their brain will react accordingly, forming a loop.

The name MU is an initialism of Mirror Unconscious, as the project mirrors the unconscious processes of the participant. It is also a reference to Hofstadter's Gödel, Escher, Bach, where the author talks about strange loops.
